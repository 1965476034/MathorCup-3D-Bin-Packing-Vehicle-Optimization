# MathorCup 3D Packing Optimization

## 项目简介
该项目面向真实物流运输场景，研究在多车型、多货物类别、多装载规则和多优化目标约束下，如何制定合理的装箱方案与车辆配置方案。问题不仅需要考虑货物是否能够装入车厢，还需要同时处理空间利用率、载重利用率、堆叠稳定性、易碎件规则、方向约束、车辆数和运输成本等因素。

在建模过程中，我将问题拆解为一个分层优化系统：

* **下层：单车三维装箱模型**
  在单辆车内部，考虑货物尺寸、重量、可旋转方向、边界约束、不重叠约束、支撑稳定性、易碎件不可承重、定向件完整支撑等规则，生成合法且高质量的单车装载方案。

* **上层：车辆配置与模式覆盖模型**
  将下层生成的单车装载方案抽象为“装载模式”，再通过混合整数线性规划模型选择不同模式的组合，从而实现总车辆数最少或总运输成本最低。

该项目的核心思想并不是简单地“把车厢装满”，而是把真实物流系统中的复杂业务规则转化为可计算的约束、目标和算法流程，形成一个可解释、可扩展的运输优化框架。
